TERRARIA — СЕРВЕР ДЛЯ ДРУЗЕЙ

============================================================
БЫСТРЫЙ ЗАПУСК НА ЛЮБОМ КОМПЬЮТЕРЕ:
1. Распакуйте архив Terraria_Server_Portable.zip в любую удобную папку.
2. Запустите файл «Запустить Панель.exe» (или «Запустить Панель.bat»).
   • Устанавливать Python, базы данных или .NET НЕ ТРЕБУЕТСЯ — всё уже полностью автономно встроено в сборку!
3. В открывшейся кибер-панели выберите мир и нажмите «Запустить сервер».
============================================================

ПАНЕЛЬ УПРАВЛЕНИЯ
• Открой «Запустить Панель.exe» (или «Запустить Панель.bat»).
• Панель не запускает сервер сама. Нажми «Запустить», когда будете готовы играть.
• «Обзор»: состояние и адрес подключения. «Игроки»: список, группы, координаты и кик.
• Между уже открытыми разделами панели можно ходить боковыми кнопками мыши: Mouse4 — назад, Mouse5 — вперёд.
• В небольшом окне меню сворачивается в значки, страницы перестраиваются, а длинные разделы прокручиваются колесом мыши.
• «Серверы»: каждый профиль — отдельный сервер со своими настройками, паролем и аккаунтами TShock. Новый профиль по умолчанию создаёт новый чистый мир; при создании можно вместо этого выбрать существующий.
• В блоке «Выбор мира» выбери мир для текущего профиля. «Создать мир» создаёт новый с выбранными размером и режимом; «Добавить существующий» копирует выбранный .wld в папку сервера, не трогая оригинал.
• «Переименовать» меняет имя файла мира, но не его внутреннее имя. «Удалить» перемещает мир в Worlds\Backups\Deleted, чтобы его можно было вернуть.
• Если несколько профилей выберут один и тот же файл мира, они будут использовать общий мир. Для отдельного прогресса оставляй каждому профилю свой мир.
• Серверы работают по очереди на порту 7777. Перед переключением профиля останови текущий сервер с сохранением.
• «Нагрузка»: только процессор и оперативная память процесса Terraria/TShock. Если сервер запущен отдельно от панели, процесс находится по игровому порту.
• «Консоль»: журнал, команды TShock и сообщения в игровой чат.
• «Админка»: выбери онлайн-игрока в списке имени или введи аккаунт вручную; таблица показывает все зарегистрированные аккаунты, их группы, права и статус онлайн.
• В «Админке» выбери аккаунт или группу, чтобы посмотреть действующие права. «Разрешить» и «Запретить» меняют право TShock; например, `tshock.admin.kick` даёт команду `/kick`.
• Чтобы изменить роль игрока, выбери его строку в таблице, затем в поле «Выдать группу» выбери любую существующую группу (например, `admin`, `superadmin`, `default` или созданную тобой) и нажми «Назначить выбранному». Для `admin` и `superadmin` панель попросит подтверждение.
• В списке прав можно выделить несколько строк через Ctrl/Shift или перечислить права через запятую, затем применить их все разом.
• Права обычной группы общие для всех её участников. Для выдачи одной команды только одному игроку выбери его аккаунт и нажми «Создать личную группу», затем добавь нужное право.
• Чтобы остановить сервер, нажми «Остановить с сохранением» и дождись подтверждения в журнале.
• Запасной запуск остался в Start Server.bat в папке сервера.

ДАННЫЕ СЕРВЕРА
Terraria: 1.4.5.8
TShock: 6.2.1
Мир FriendsWorld: большой, классическая сложность
Адрес на этом же ПК: 127.0.0.1
Порт игры: 7777
Слотов: настраиваются отдельно в каждом профиле.
Пароль входа: смотри и меняй для выбранного профиля во вкладке «Серверы» или «Настройки» панели.

КАК ОДИН РАЗ СДЕЛАТЬ СЕБЯ ВЛАДЕЛЬЦЕМ
1. Нажми «Запустить» в панели и дождись загрузки мира.
2. В Terraria на своём ПК: Multiplayer → Join via IP.
   IP: 127.0.0.1, порт: 7777, текущий пароль из вкладки «Настройки» панели.
3. Для выбранного профиля в игровом чате введи его одноразовый код со вкладки «Админка»:
   /setup КОД
   Панель показывает код для текущего профиля. Не отправляй его друзьям.
4. Создай аккаунт владельца, придумав личный пароль без пробелов:
   /register ТВОЙ_ЛИЧНЫЙ_ПАРОЛЬ owner
5. Войди под аккаунтом владельца:
   /login ИМЯ_ТВОЕГО_ПЕРСОНАЖА ТВОЙ_ЛИЧНЫЙ_ПАРОЛЬ
6. Закончи настройку командой /setup.

Пароль владельца отличается от пароля сервера. Никому его не сообщай: аккаунт имеет полные права. Вместо слов «ТВОЙ_ЛИЧНЫЙ_ПАРОЛЬ» введи свой пароль.

КАК ПОДКЛЮЧИТЬ ДРУЗЕЙ
• Для кроссплея нужна совместимая версия Terraria 1.4.5.8 на ПК и телефоне. В игре выберите Multiplayer → Join via IP, введите адрес хоста, порт 7777 и пароль сервера.
• При первом входе друг создаёт аккаунт: /register СВОЙ_ПАРОЛЬ. Если попросят войти: /login ИМЯ_ПЕРСОНАЖА СВОЙ_ПАРОЛЬ.
• Для неофициальных или изменённых клиентов подключение не гарантируется: версия и сетевой протокол должны совпадать.

ЕСЛИ ДРУЗЬЯ В ДРУГИХ ДОМАХ
Hamachi не обязателен, но всем нужен общий доступ к сети. Попробуй бесплатный ZeroTier:
Скачать: https://www.zerotier.com/download/
Начальная инструкция: https://docs.zerotier.com/start/
Поддерживаемые устройства: https://docs.zerotier.com/compatibility/
Создай сеть, пусть друзья установят ZeroTier и вступят по ID сети; подтверди их устройства. Друзья вводят ZeroTier-IP твоего ПК и игровой порт 7777. REST-порт 7878 друзьям открывать не нужно.
Альтернатива — пробросить TCP-порт 7777 на роутере и разрешить сервер в брандмауэре Windows, затем отправить друзьям внешний IPv4. Адрес 127.0.0.1 работает только на твоём ПК. Не отправляй друзьям пароль владельца или одноразовый код.

ФАЙЛЫ И СОХРАНЕНИЯ
Миры лежат в Worlds и называются так же, как в панели. Папки дополнительных серверов в ServerProfiles тоже называются по имени профиля; при переименовании сервера папка меняет имя. Основной профиль — в tshock; параметры списка профилей — в Panel.
• Кнопка «Удалить сервер» навсегда удаляет папку профиля и аккаунты TShock. Если его мир не используется другим профилем, панель также удаляет файл мира и связанные копии. Удаление нельзя отменить.
Для резервной копии останови сервер штатно и скопируй всю папку «Terraria server».
Панель использует локальный REST API. Токен хранится в config.json внутри папки соответствующего профиля — не публикуй эти файлы. До настройки сохранена копия исходного config.json.before-panel-*.bak.
